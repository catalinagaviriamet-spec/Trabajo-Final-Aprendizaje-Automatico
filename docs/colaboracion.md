# Colaboración del equipo

en el diseño del proyecto y la discusión de las decisiones metodológicas. Las siguientes

## Cómo registrar los aportes

1. La propietaria invita a las compañeras como colaboradoras del repositorio.
2. Cada compañera acepta la invitación desde su propia cuenta.
3. Cada una realiza cambios reales: explicaciones del EDA, interpretación de resultados,
   pruebas, código o guías que haya desarrollado o revisado y mejorado.
4. Los cambios se proponen en una rama y una pull request para que el equipo los revise.
5. Cada integrante conserva la autoría de sus commits y describe qué cambió y por qué.

La [guía oficial de GitHub para invitar colaboradoras](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/managing-repository-settings/inviting-collaborators-to-a-personal-repository)
explica el proceso. Las invitaciones y su aceptación están pendientes de comprobar;
listar una cuenta aquí no concede acceso al repositorio.

El profesor solicita commits propios de cada integrante. La participación conjunta
en las decisiones se documenta aquí; su evidencia en Git se construye mediante los
aportes reales de cada cuenta. Esta actualización no modifica la autoría de commits
anteriores ni acredita aportes individuales que todavía no se hayan registrado.
